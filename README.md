# Tetris Arena

A production-ready Next.js 14 App Router Tetris game with a pure TypeScript engine, SRS rotation, AI opponent, local battle fallback, and Ably integration points.

## Run

```bash
pnpm install
pnpm dev
```

`NEXT_PUBLIC_ABLY_KEY` is optional. Without Ably credentials, battle mode uses an in-memory local room.

## Checks

```bash
pnpm test
pnpm build
```
